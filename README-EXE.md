# 燃卡快查 v2.5（Windows 便携版）

直接双击 `CalorieCompass-v2.5-portable.exe` 运行，无需安装。

v2.5 保留 v2.4 原有界面、导航和功能流程，新增：

- “我的数据”支持新增、修改和删除自定义菜品，数据只保存在本机。
- “热量对比”支持搜索并自行添加/移除菜品，也可从详情页直接加入。
- 热量快查图片全部随软件本地部署，不再在启动或浏览时联网查询。
- 快查目录保留全部 50 条基础记录，并扩展为 128 条经过图片准确性复核的记录。
- 每条菜品使用独立固定图片；低质量网图已剔除，核心缺图采用统一风格 AI 食物摄影。

- 可编辑并持久保存每日食谱与训练动作，自动汇总每日和每周热量。
- 周报可导出为 PNG 图片。
- 食物按主营养来源分类，并扩充离线食物数据和逐条匹配图片。
- 千焦与大卡支持双向输入和换算。

所有初始数据和计算均可离线使用。估算值仅供记录参考。
