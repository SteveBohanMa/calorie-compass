# 燃卡快查 v2.8（Windows 便携版）

直接双击 `CalorieCompass-v2.8-portable.exe` 运行，无需安装。

v2.8 重做了训练消耗估算，并补上饮食这边几个常用功能：

- **训练估算重做。** 先填一次身体数据（性别、年龄、身高、体重，只存在本机），之后每个动作都按你的数据计算。
  - 力量训练按实际做功和肌肉效率估算：53 个动作，可按部位（腿臀、胸、背、肩、手臂、核心、有氧、综合）和器械（杠铃、哑铃/壶铃、器械、绳索、自重等）筛选或搜索。哑铃按单只重量、倒蹬按挂片重量、辅助引体按辅助重量填写即可。
  - 有氧按 ACSM 公式（步行、跑步、功率车）和 2024 成人身体活动纲要（划船机、椭圆机、楼梯机、跳绳、HIIT 等）计算，并扣除你自己的静息代谢。
  - 高级参数都可以不填：填了组间休息，就计入组间恢复和训练时段的静息代谢；不填只显示训练部分，并说明哪些没计入。练后恢复始终计入。动作节奏、RPE 和平均心率填了才会参与计算，明显不合理的心率不会被使用。
  - 结果给出范围、分项（组内做功、组间恢复、练后恢复、静息代谢）和完整的计算依据与参考文献。
- **旧训练记录会被清除。** v2.7 及更早版本里的训练记录是占位数字，升级后不再保留；饮食记录不受影响。
- **份量换算和“使用此数据”。** 食物详情里可以按实际克数换算热量和营养素，关东煮按串/个计、每串重量可改；一键记入今天的早餐、午餐、晚餐或加餐。
- **按实际份量对比。** 热量对比可以在“每 100 克”和“按实际份量”之间切换，例如米饭 150 克对比 4 串关东煮。
- **收藏。** 常吃的食物点爱心收藏，首页“收藏”直接打开。
- **备份更完整。** 导出的备份包含身体数据、收藏和份量设置；导入旧版本的备份不会覆盖这些。

从 v2.7 升级不会丢饮食数据、自定义菜品和对比列表。

所有数据和计算均可离线使用。估算值仅供记录参考。
