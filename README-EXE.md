# 燃卡快查 v2.7（Windows 便携版）

直接双击 `CalorieCompass-v2.7-portable.exe` 运行，无需安装。

v2.7 是数据重建的第一批，界面和功能流程与 v2.6 保持一致：

- **数据全部换成可追溯的来源。** 目录里的 123 种食物来自 USDA FoodData Central 和日本食品标准成分表（八订）增补2023，每条都写明数据库和条目编号。
- **营养素回来了。** 每种食物都显示蛋白质、碳水、脂肪和纤维，全部和热量交叉校验过。
- **可信等级 A/B/C。** A 是来源里直接有这种做法的熟制值；B 是相近做法或简单配方推算；C 是各家产品差别大的典型值，以包装为准。需要注意的地方（例如“可食部”“刷的油另算”）显示在“说明”里。
- **关东煮扩充到 27 种。** 新增的条目暂时用图标代替照片。
- **钠提示。** “卤·炖”和“关东煮”列表顶部提醒汤汁含盐高。
- **清单调整。** 删除了 24 种国内少见或重复的食物；生四季豆改为水煮四季豆；小米粥和菜包等中国食物成分表到手后再上线。

从 v2.6 升级不会丢数据。每周计划里已经记下的餐食保留当时的热量数值。

所有数据和计算均可离线使用。估算值仅供记录参考。
