# 燃卡快查 · Calorie Compass

一款以离线使用为核心的开源饮食与训练记录小工具，使用 React、TypeScript 和 Electron 构建。

> [!WARNING]
> **营养数据免责声明**
>
> 当前内置的食物热量、营养成分、份量以及训练消耗数据主要用于软件功能演示，其中包含通用参考值、配方估算值和低置信度记录，尚未全部通过权威数据源逐条校准。数据可能不准确、不完整，也可能不适用于特定品牌、烹饪方式或个人情况。
>
> 请勿将本项目中的数据用于医疗诊断、疾病管理、专业营养方案、精确减重决策或其他需要高准确度的用途。实际饮食与训练决策应以食品标签、可信数据库以及医生或注册营养专业人士的建议为准。

## 项目简介

燃卡快查将常用的饮食查询、训练消耗估算和每周计划集中在一个轻量桌面应用中。应用的核心内容随软件一同打包，主要功能可以离线使用，用户添加的菜品和计划数据保存在本机。

当前公开版本为 **v2.5**，定位为软件功能与交互实现优先的开源小项目。后续版本将逐步使用可信来源重新核对和替换内置营养数据。

## 主要功能

- 中英文界面切换
- 按烹饪方式和营养分类查询食物
- 查看每 100 克及每份热量和营养成分
- 多种食物热量对比
- 添加、编辑和删除自定义菜品
- 训练消耗区间估算
- kcal 与 kJ 双向换算
- 按天编辑饮食与训练计划
- 自动汇总每周计划并导出 PNG 周报
- Windows 便携版，无需安装

## 技术栈

- React 19
- TypeScript
- Vite
- Electron

## 本地开发

环境要求：Node.js 20 或更高版本、npm。

```bash
npm ci
npm run dev
```

启动桌面应用：

```bash
npm run desktop:run
```

构建 Windows x64 便携版：

```bash
npm run desktop:dist
```

构建产物会生成在 `release-v2.5/`，该目录不会提交到 Git 仓库。可执行文件应通过 GitHub Releases 发布。

## 检查与测试

```bash
npm run check:runtime
npm run test:v25-data
npm run test:sites
npm run test:runtime
```

首次运行 Playwright 测试前，需要安装对应浏览器：

```bash
npx playwright install chromium
```

## 项目结构

```text
desktop/    Electron 主进程与预加载脚本
public/     随应用打包的本地图片和静态资源
scripts/    数据、资源和构建辅助脚本
src/        React 应用、目录数据与业务逻辑
tests/      Playwright 与 Sites 测试
worker/     静态站点路由 Worker
```

## 数据计划

目前的数据校验主要保证记录结构、字段范围和本地资源完整性，并不代表营养数值已经获得权威验证。后续数据更新计划包括：

1. 确定允许再分发的可信营养数据库。
2. 为每条记录保留来源、来源 ID、更新时间和可信等级。
3. 对热量与三大营养素进行一致性检查。
4. 将估算数据和权威来源数据明确区分。

欢迎针对软件功能、界面、可访问性和工程实现提交 Issue 或 Pull Request。涉及营养数据的修改，请同时提供可核查的数据来源。

## 隐私

应用不要求注册账号。自定义菜品、对比选择和周计划保存在用户本机，项目本身不提供云端同步服务。
