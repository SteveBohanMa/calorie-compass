# Food image sources

The first visual prototype uses local food photography while generated cartoon assets are unavailable.

- `steak.jpg`: “Steak auf Grill” by Jon Sullivan, released to the public domain / CC0 via PDPhoto.org. Source: https://commons.wikimedia.org/wiki/File:Steak_auf_Grill.jpg
- `chicken.jpg`: “Grilled Chicken Breasts” by Sharon Chen, licensed CC BY 2.0. Source: https://commons.wikimedia.org/wiki/File:Grilled_Chicken_Breasts_(28905381261).jpg

These files are stored locally so the prototype’s core lookup flow remains usable offline.

## Oden pictures (v2.7)

`catalog/od-*.svg` are stand-in pictures for the oden items added in v2.7, generated by
`scripts/nutrition/build_oden_icons.py`. Each shows a Noto Emoji icon on the app's tone colour.

- Noto Emoji by Google Inc., Apache License 2.0. Source: https://github.com/googlefonts/noto-emoji (via `@iconify-json/noto`)
